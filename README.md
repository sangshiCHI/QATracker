# QATK 0.1.5

QuestAway 的中文桌面助手。

## 开始使用

- 解压后双击 QATK.exe 即可使用，无需另外安装运行环境。
- 当前提供 Windows x64 版本，建议使用 Windows 11；其他系统环境尚未完整验证。
- 游戏已启动时会自动连接，未启动时会等待游戏。
- 游戏关闭后，助手会保存记录并自动退出。

## 主要功能

- 显示本次装备产出总数，以及各品质颜色的数量。
- 装备产出包含开箱、转化和制造，不包含材料和宝石。
- 显示最近保存时间和本次记录时长。
- 右下角显示当前版本号，可在「关于」查看版本和检查更新。
- 统计框跟随游戏移动，可放在游戏的左、右、上、下方。
- 点击 wiki 搜索中文资料，图标和图片也可离线查看。
- 支持按章节主题搜索，如等级差、离线进度、附魔，也可搜索装备品质和家具风格。
- 搜索框点击外面即可收起，资料详情点击右上角关闭。
- 点击「挂机」最小化游戏，用助手查看地图、文字波次、药水和角色经验。
- 挂机窗口可以拖动、调整大小和收起，点击「恢复」返回游戏。
- 地图、已清波次和估算刷图时间显示在同一行。
- 角色经验以进度条显示，并根据经验增长估算升级时间。
- 可开启补药水提醒和巨像提前提醒。

## 设置与操作

- 点击右下角齿轮打开设置。
- 透明度、大小和停靠方向调整后立即生效。
- 右键任务栏旁的战士托盘图标，可显示或隐藏助手、切换挂机、打开设置、检查更新、查看关于或退出。
- 助手收起后，可在托盘菜单中选择显示。

## 版本更新

- 发现新版本时，会显示版本号和更新内容。
- 普通模式和挂机模式都能收到更新提示，挂机窗口收起时也可查看。
- 挂机时可直接更新，成功后保留挂机状态、窗口位置和统计记录。
- 选择「立即更新」后才会下载，也可以选择「稍后」。
- 下载时可查看进度或取消，更新失败时仍可使用旧版。
- 网络不通时可稍后再检查，不影响本地统计和 wiki。

## 使用提醒

- 统计和挂机信息随游戏保存刷新，可能稍晚于游戏画面。
- 本次记录时长包含等待和暂停时间。
- 数据不完整时会提示，不能把未读取到的数据当成没有收益。
- 挂机时游戏仍在运行，实际资源占用取决于游戏和电脑。
- 助手不修改游戏存档，也不会替你操作游戏。
- 软件运行时会默认发送匿名在线信号，用于汇总在线软件数量、版本及大致地区。
- 在线信号使用本次运行的临时随机标识，不包含游戏账号、存档、装备或硬件标识。
- 地区按网络出口估计，不获取精确位置；我们的统计库不保存原始 IP，临时在线记录失效后自动删除。
- 网络服务商仍会处理连接所需的网络信息；断网不影响本地统计，在线数量不代表真实人数。

- 默认自动查找游戏和存档，不需要手动输入路径。
- 没找到时，在设置的「连接位置」点击「重新查找」或「浏览文件」。
- 手动选择后，点击「自动查找」可以恢复自动查找。
